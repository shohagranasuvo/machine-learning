# Machine Learning

Python studies, experiments, and project work covering the machine-learning workflow from data preparation through model training and evaluation.

## Repository layout

- `Machine Learning Code/` — learning exercises and implementations
- `ML_Project/` — project work and experiments
- `BackgroundStudyForProject/` — supporting research and background material

## Status

Academic learning and project repository. Individual notebooks and scripts may have their own data or environment requirements. Inspect each project folder before running it.

## Getting started

1. Clone the repository.
2. Open the relevant project folder.
3. Create a Python virtual environment for that project.
4. Install the dependencies documented by the project, if provided.
5. Run the notebook or script from its project directory.

## Notes

Datasets, model results, and experiments are kept with their related coursework where possible. This repository is intentionally a learning archive rather than a single packaged application.
